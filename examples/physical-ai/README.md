# Physical AI Reference Implementation

This example maps the currently operating FlyPig AI Physical AI research system into the generic Topic Intelligence model.

It is a reference implementation, not a duplicate production database. Production state remains in the `flypigai.ca` repository.

中文摘要：這裡是 Physical AI 的標準化映射範例，用來示範如何把真實運行中的研究系統套進通用模板。實際 production state 仍留在 `flypigai.ca`。

## Topic objective

Primary question:

> Who becomes the Android of Physical AI?

The system tracks whether Physical AI is moving from vertically integrated robot systems toward reusable layers such as reference robots, runtime / middleware, capability interfaces, robot skills, foundation models, edge compute platforms, and application ecosystems.

## Production source roles

### Taiwan collector

Purpose: supply-side, components, edge compute, embedded platforms, sensors, robotics commercialization and Taiwan manufacturing signals.

### Canada collector

Purpose: robotics, autonomy, deployment, industrial demand, commercialization, procurement, research and ecosystem evidence.

### Global Strategic Signals

Purpose: only major global events with material implications for the Physical AI stack or registered predictions.

This is not a third generic news desk.

## Evidence promotion

A Taiwan, Canada or global signal is promoted into the Physical AI evidence tracker only when it affects a registered prediction.

Direction:

- supports
- weakens
- neutral
- invalidates

Strength is scored independently.

## Prediction layer

The production implementation currently tracks predictions such as:

- emergence of an Android-like common layer for Physical AI
- emergence of reusable reference robot platforms
- value migration from hardware toward runtime, skills, applications and operating data
- robot skills becoming reusable application primitives

The original prediction wording and first publication date are immutable.

## Publication layer

Industry Signals may publish frequently after verification and audit.

Long-form `Physical AI Goes Modular` Insights publish or materially update only when evidence changes a thesis, resolves an uncertainty, reveals a structural pattern, or supports a new falsifiable prediction.

## Key lesson

The important architectural separation is:

```text
Signals = what happened
Evidence = what matters to a thesis
Prediction = what we expect next
Insight = what the accumulated evidence now means
```

中文摘要：Signals 回答「發生什麼」、Evidence 回答「什麼值得影響判斷」、Prediction 回答「接下來可能發生什麼」、Insight 回答「累積證據現在代表什麼」。
